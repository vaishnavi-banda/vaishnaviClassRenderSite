# Project 1: Personal Finance Hub
This repository contains the foundational landing page and static site deployment setup for CMSC335: Web Development with JavaScript at the University of Maryland, College Park.
CMSC335 (Web Development with JavaScript) teaches modern Web application development. The course focuses on building client-side and server-side applications using JavaScript, dynamic web content generation, DOM manipulation, asynchronous programming (Promises, async/await), HTTP/REST protocols, and server architectures (such as Node.js and Express).

My page focuses on the value of Personal Finance Education. It aims to highlight how a lack of Personal Finance education impacts generational wealth and the efforts people can take to contribute to the initiative of education.
